# VirtualStreet

## Project Purpose
VirtualStreet is an innovative browser-based 3D virtual e-commerce platform. It provides an immersive online shopping experience where customers can walk through a virtual street, explore virtual shops and buildings, and eventually browse and purchase normal 2D e-commerce products inside them.

## Current Phase
**Phase 1: Project Setup and Foundation**
- Set up a clean React + TypeScript + Vite frontend project.
- Configured Tailwind CSS for styling.
- Installed and verified Three.js, React Three Fiber, and Drei with a placeholder 3D scene.
- Set up Zustand for state management with basic typescript definitions for future use.
- Established a scalable frontend folder structure.

## How to Install Dependencies
To install the project dependencies, run the following command in the project root:
```bash
npm install
```

## How to Run the Frontend
To start the development server, run:
```bash
npm run dev
```
Then, open the provided local URL (usually `http://localhost:5173`) in your browser to view the application.
